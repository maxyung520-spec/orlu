## 🚀 How to Install & Update / 安裝與更新方法

1. **First-time install**: Download `Orlu-Windows-x64-<version>.zip` from [Releases](https://github.com/maxyung520-spec/orlu/releases/latest), unzip it, and run `Orlu-Windows-x64/Orlu.exe`.
2. **In-app Auto-Update**: Orlu automatically checks this repository for new releases on startup. When a newer version is published, click **⬇ 一鍵更新 (Download & update)** in the sidebar or go to **⚙ Setting → 版本更新 · GitHub Releases** to update in place while keeping all your conversations, projects, and settings.
